Dalam operasi pencarian dan penyelamatan, komunikasi sering terhambat karena jaringan seluler terbatas atau rusak, terutama di wilayah terpencil dan terdampak bencana. Padahal tim di lapangan dan posko harus tetap tahu di mana setiap personel berada.

Apa itu SAR-Mesh

Komunikasi
tanpa internet.

SAR-Mesh adalah sistem komunikasi darurat berbasis LoRa 433 MHz. Pesan dan lokasi personel dikirim dari node ke node hingga sampai di posko, tanpa bergantung pada internet maupun jaringan seluler.

Cara kerja

Tiga node.
Satu jaringan.

01

Field Node

Dibawa petugas di lapangan. Mengirim posisi GPS dan pesan status lewat tiga tombol.

02

Relay Node

Meneruskan paket dari node ke node untuk memperluas jangkauan jaringan.

03

Command Node

Di posko. Menerima data lalu meneruskannya ke laptop untuk dipantau.

Keandalan

PDR per konfigurasi

Persentase paket dari Field yang sampai di Command.

Hanya TX dalam jendela log Command; perubahan lokasi dan interval tidak dikendalikan.

Kecepatan

Estimasi Time on Air

Waktu satu paket berada di udara. Makin besar SF, makin lama.

Estimasi teoretis, bukan latency terukur; asumsi preamble 8, explicit header, CRC on, CR 4/5.

Kuat sinyal

Rata-rata RSSI paket diterima

Makin tinggi (mendekati 0 dBm), makin kuat sinyal yang diterima.

Hanya paket RX: paket yang hilang tidak memiliki nilai RSSI/SNR.

Kualitas sinyal

Rata-rata SNR paket diterima

Rasio sinyal terhadap derau. LoRa masih bisa menerima di bawah 0 dB.

Hanya paket RX: paket yang hilang tidak memiliki nilai RSSI/SNR.

Sepanjang pengujian

Perubahan keberhasilan penerimaan

PDR dihitung per jendela 3 menit dari 11:45 sampai 13:02.

Angka nol pada jendela aktif menunjukkan tidak ada RX yang cocok. Jeda log diarsir. Nilai dibaca dari grafik hasil olah data tim.

Sebaran

Hubungan RSSI dan SNR

Setiap titik adalah satu paket yang berhasil diterima.

Lokasi

RSSI vs perpindahan GPS Field

Perpindahan relatif dari posisi GPS Field pertama, bukan jarak antarnode.

Garis putus: 500 m dari FIX awal (bukan posisi Command).
